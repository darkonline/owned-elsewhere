# Owned Elsewhere — проверка библиотек для Steam

[English version](README.md)

Расширение для браузера: в магазине Steam отмечает игры, которые у вас уже есть в **других** библиотеках —
Epic Games Store, GOG, Xbox / Microsoft Store, Ubisoft Connect, EA app, Amazon Games, Battle.net, itch.io и других, —
чтобы не купить одну игру дважды.

## Что показывает

- **Страница игры:** одна плашка над вариантами покупки — «Эта игра у вас уже есть: Epic Games Store».
- **Наборы и пакеты из нескольких игр:** какая часть уже есть — «Из этого набора у вас уже есть 1 из 2» и названия.
  Подписки (например, GTA+) и внутриигровая валюта не отмечаются.
- **Страницы DLC:** есть ли у вас основная игра.
- **Поиск, список желаемого, корзина, подборки:** отметка под названием и подсветка строки.
- **Три уровня:** *есть* (фиолетовый) — куплено в другом магазине; *возможно* (пунктир) — библиотеки Xbox, где бывают игры из
  Game Pass, консольные версии или совпало только другое издание (например, GTA V и GTA V Legacy); *уже в Steam* (серый).
  Уровень каждого магазина настраивается, а любую игру можно исключить кнопкой × на плашке.
- **Xbox:** версии для ПК и консоли различаются; в разделе «Проверка игр Xbox» каждую игру можно подтвердить (в том числе таблицей).
- **macOS / Linux:** версии только для Windows в других магазинах показываются как «возможно есть».
- **Скрыть в Steam:** одна кнопка включает штатное «Скрыть» Steam с причиной «Есть в другом магазине».
- **Списки игр профилей** (ваших и друзей) на steamcommunity.com — по желанию, доступ запрашивается при включении.

Сравнение идёт по **Steam App ID**, если источник его даёт (GOG Galaxy — для большинства игр из всех подключённых
магазинов), иначе — по нормализованному названию. Совпадения по названию помечаются.

## Источники

| Источник | Файл | Сравнение |
| --- | --- | --- |
| GOG Galaxy 2.0 | `C:\ProgramData\GOG.com\Galaxy\storage\galaxy-2.0.db` (сначала закройте Galaxy) | Steam ID примерно для 90% игр |
| Playnite | CSV из дополнения Library Exporter Advanced (Название, Источники, Платформы), любой язык Playnite | название; Steam ID для игр Steam |
| GOG Galaxy Export Script | `gameDB.csv` | название |
| Heroic Games Launcher | `store_cache/legendary_library.json`, `gog_library.json`, `nile_library.json` | название |
| Любой CSV / TSV | если заголовки не распознаны — выбор колонок; можно указать колонку Steam App ID | название или Steam ID |
| Список | вставить текст или `.txt`, одна игра на строку, можно `| магазин` | название |
| Резервная копия | `.json`, сохранённый расширением | — |

Можно загрузить несколько источников сразу; повторная загрузка заменяет только этот источник.

## Конфиденциальность

Все данные хранятся только в браузере (`chrome.storage.local`). Расширение ничего никуда не отправляет; единственный
запрос — к публичному API Steam (`store.steampowered.com/api/packagedetails`) со страниц магазина Steam, чтобы узнать
состав пакета. Подробнее — [PRIVACY.md](PRIVACY.md).

## Установка из исходников

1. `chrome://extensions` (или `edge://extensions`) → «Режим разработчика» → «Загрузить распакованное» → папка `extension`.
2. Firefox: `about:debugging` → «Этот Firefox» → «Загрузить временное дополнение» → `dist/firefox/manifest.json` (сначала `npm run build`).

## Разработка

```bash
npm install
npm test
npm run e2e -- путь/к/galaxy-2.0.db
npm run build
```

Строки интерфейса — в `tools/locales.js` (английский и русский), `npm run locales` пересобирает `extension/_locales`.
