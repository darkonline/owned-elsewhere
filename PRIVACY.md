# Privacy policy — Owned Elsewhere

_Last updated: 22 November 2026_

**Owned Elsewhere does not collect, transmit, sell or share any personal data.**

- The game library files you import (GOG Galaxy database, CSV, JSON, text) are read locally in your browser.
  Only the game titles, store names and Steam App IDs extracted from them are saved, in the browser's extension
  storage (`chrome.storage.local`) on your device. Nothing is uploaded.
- The extension runs only on `store.steampowered.com`. To show how much of a package you already own, it may request
  the public Steam endpoint `https://store.steampowered.com/api/packagedetails` for the package shown on the page.
  The request contains only the package number and is made without cookies.
- Only if you press "Hide in Steam", the extension sends Steam's own "ignore this game" request for that game, as the
  Steam page itself would. Only if you turn on badges for profile game lists, it also runs on `steamcommunity.com` game lists.
- No analytics, tracking, advertising or remote code.
- You can delete all stored data at any time on the extension's options page ("Remove all") or by removing the extension.

# Политика конфиденциальности — Owned Elsewhere

**Owned Elsewhere не собирает, не передаёт, не продаёт и не раскрывает никаких персональных данных.**

- Загружаемые файлы библиотек (база GOG Galaxy, CSV, JSON, текст) читаются локально в браузере. Сохраняются только
  названия игр, названия магазинов и Steam App ID — в хранилище расширения (`chrome.storage.local`) на вашем устройстве.
  Ничего никуда не отправляется.
- Расширение работает только на `store.steampowered.com`. Чтобы показать, какая часть пакета у вас уже есть, оно может
  запросить публичный адрес Steam `https://store.steampowered.com/api/packagedetails` для пакета на странице. Запрос
  содержит только номер пакета и отправляется без cookies.
- Только когда вы нажимаете «Скрыть в Steam», расширение отправляет штатный запрос Steam «скрыть эту игру» — так же, как
  это сделала бы сама страница. Только если вы включите отметки в списках игр профилей, оно работает и на `steamcommunity.com`.
- Нет аналитики, отслеживания, рекламы и удалённого кода.
- Все данные можно удалить на странице настроек («Удалить все») или удалив расширение.
